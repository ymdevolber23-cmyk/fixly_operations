Fixly Operations — نسخة متعددة الصفحات

افتح index.html من خلال خادم ملفات محلي، ثم استخدم القائمة الجانبية للانتقال بين الصفحات. تم فصل كل مهمة في ملف HTML مستقل.

للتشغيل المضمون: افتح الطرفية داخل المجلد وشغّل python3 -m http.server 8080 ثم افتح http://localhost:8080. ويمكن تجربة فتح الصفحات مباشرة، لكن الخادم المحلي هو الخيار الأفضل.

الصفحات

غرفة العمليات، البلاغات، إنشاء بلاغ، تفاصيل البلاغ، وضع الفني، الفنيون، المخزون، التقارير، العملاء والعقارات، المناطق والتغطية، والإعدادات.

مهم

هذه نسخة Demo أمامية ببيانات محلية. الصور البصرية مستضافة عبر روابط المشروع، لذلك يلزم اتصال إنترنت لظهورها.
